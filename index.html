Connect GitHub to add media

Images and videos are saved into the repo, so everyone who opens the site sees them. Connect once per browser with a token that can only change this repo.

  1. Open GitHub’s new token page.
  2. Under Repository access, pick Only select repositories and choose .
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it, and paste it below.

The token stays in this browser only and is sent only to GitHub. The repo is public, so uploaded files are public too.
